🎧 Play_now

Play_now — это стриминговый сервис для меломанов.
Он помогает:

🎵 подбирать музыку с помощью алгоритмов рекомендаций
📂 создавать, хранить и управлять плейлистами
▶️ воспроизводить треки прямо в браузере

Сервис ориентирован на удобство, скорость и современный пользовательский опыт.

## 🚀 Установка и запуск проекта

1. Для запуска данного проекта вам понадобится nodejs и npm.
2. Склонируйте данный репозиторий к себе на диск. Затем выполните: `npm i`.
3. Режим разработки: `npm run dev`. Запускает проект с использованием Vite для разработки с горячей перезагрузкой.
4. Продакшн-сборка: `npm run build`. Создает оптимизированную сборку проекта в папку dist.
