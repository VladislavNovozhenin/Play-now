## ⚙️ Инициализация

Для инициализации необходимо отдельно скачать папку static, которая содержит статичные файлы БД. Папку необходимо разархивировать так, чтобы она была доступна по пути /streaming_service_api/static
Ссылка на скачивание - https://disk.yandex.ru/d/SkL3LhjHefqglQ

После того как данная папка будет на своем месте, можно выполнять команды по инициализации.

Миграция - процесс наполнения вашей базы данных данными о музыке, исполнителях, обложках и т.д. Ее необходимо сделать единожды при инициализации БД.

`npm install`
`npm run migration`

## 🚀 Запуск приложения

В режиме разработки

`npm run start`

Важно: для работы используйте Node.js версии 16–18

## 📄 Swagger UI

Для удобной работы с API используется Swagger, доступный после запуска сервера по адресу: http://localhost:3000/api/

Как работать со Swagger
Найдите маршрут /api/auth/register.
Зарегистрируйтесь и получите токен в ответе сервера.
Скопируйте токен и вставьте его в поле Authorize в верхней части страницы.
После авторизации вам будут доступны все функции API.

⚠️ Авторизация через Swagger не заменяет авторизацию в клиентском приложении. Она нужна только для тестирования API.
